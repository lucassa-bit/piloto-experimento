# Lexical Context

- Game é uma sessão de estimativa colaborativa identificada por uma URL própria.
- Estimator é um participante autorizado a entrar na sessão e fornecer estimativas.

# Operational Context

- O nome deve conter entre 1 e 50 caracteres não compostos exclusivamente por espaços.
- Dois estimadores ativos não podem utilizar o mesmo nome dentro da mesma sessão.
- O usuário não entra no jogo e recebe uma mensagem informando que o convite é inválido ou indisponível.
- O estimador pode entrar enquanto a sessão estiver aberta para participantes.
- O estimador é adicionado à sessão e direcionado para a página ativa do jogo.

# Decisional Context

- Foi decidido permitir participação por convite sem exigir criação ou autenticação de uma conta.

# Systemic Context

- A URL contém um identificador utilizado pelo sistema para localizar a sessão correspondente.
- A associação entre o estimador e o jogo é registrada no estado da sessão.
